     ================================================================================
     HOW TO RUN THE BORING SOCIAL MEDIA APP IN A GITHUB CODESPACE
     ================================================================================
    
     This guide provides step-by-step instructions for repository viewers and developers 
     to navigate, set up, and run the Boring Social Media App inside a GitHub Codespace 
     from your desktop or browser.
    
    --------------------------------------------------------------------------------
    1. OPENING THE CODESPACE
    --------------------------------------------------------------------------------
    - Access the repository's Codespace environment directly via:
      https://animated-space-palm-tree-wrjpj7v7jv4r3g6x9.github.dev/
    - Open the integrated terminal inside your Codespace (Press `Ctrl + ~` on Linux/Windows 
      or `Cmd + ~` on macOS).
   
    --------------------------------------------------------------------------------
    2. NAVIGATING TO THE PROJECT DIRECTORY
    --------------------------------------------------------------------------------
    In the integrated terminal, navigate to this folder:
   
        cd "Research and Development/Python Projects/Boring_Social_Media_App"
   
    --------------------------------------------------------------------------------
    3. SETTING UP THE PYTHON VIRTUAL ENVIRONMENT
    --------------------------------------------------------------------------------
    Check if a virtual environment (`venv`) exists. If not, create and activate it:
   
        # Create virtual environment
        python3 -m venv venv
   
        # Activate the virtual environment
        source venv/bin/activate
   
    --------------------------------------------------------------------------------
    4. INSTALLING DEPENDENCIES
    --------------------------------------------------------------------------------
    Install all required Python packages specified in `requirements.txt`:
   
        pip install --upgrade pip
        pip install -r requirements.txt
   
    --------------------------------------------------------------------------------
    5. RUNNING THE APPLICATION
    --------------------------------------------------------------------------------
    Launch the application server:
   
        python main.py
   
    --------------------------------------------------------------------------------
    6. ACCESSING THE APP VIA PORT FORWARDING
    --------------------------------------------------------------------------------
    - GitHub Codespaces will automatically detect the running application port and prompt 
      you with a notification (e.g., "Your application is running on port XXXX").
    - Click **"Open in Browser"** to view the app, or go to the **"Ports"** tab in your 
      Codespace panel to copy the forwarded URL and view it live.
  ================================================================================
