How to Run (First-Time Setup):

  Enter the codespace: https://animated-space-palm-tree-wrjpj7v7jv4r3g6x9.github.dev/

  In the codespace terminal:

   1. cd "Research and Development/Python Projects/Boring_Social_Media_App"
   2. python3 -m venv venv
   3. source venv/bin/activate
   4. pip install --upgrade pip
   5. pip install -r requirements.txt
   6. uvicorn main:app --reload --host 0.0.0.0 --port 8000

  Open http://localhost:8000/
