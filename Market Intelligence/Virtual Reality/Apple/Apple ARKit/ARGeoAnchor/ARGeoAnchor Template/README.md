# ARGeoAnchor Template

This folder contains a consolidated Swift template reconstructed from the Apple geo-tracking sample and associated PDF references.

It is intended as a starting point for an ARKit geotracking app using `ARGeoTrackingConfiguration` and `ARGeoAnchor`.

## Files

- `ARGeoAnchorTemplate.swift` — a single-file template containing the app logic, geo anchor handling, map integration, and GPX import/export helpers.

## Notes

- This is a source template, not a compiled Xcode project artifact.
- Real execution requires an iPhone or iPad with ARKit geotracking support and an Xcode project configured for ARKit + Core Location.
- The original Apple sample uses several UIKit and RealityKit components, and this template reproduces the essential implementation pattern.
